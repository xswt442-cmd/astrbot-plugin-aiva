## [0.2.2] - 2026-10-14

### 新增

- **`get_valorant_profile` 这个 LLM 工具。** 直接问模型「我的无畏契约战绩怎么样」
  时会由模型自己调用它读提问者自己的战绩。爱农与爱完美早就有对应的工具，爱瓦
  此前只有指令这一条路。

### 修正

- **PK 的多人同名提示少了一个 `f` 前缀**，用户看到的是一句带 `{关键词}` 字面量
  的提示。
- **对方登录态过期时抛 `UnboundLocalError`。** 取双方战绩写在一个 `try` 里，
  第一句就抛异常时 `甲列表` 还没绑上，`except` 里再去读它，用户只看到机器人
  没反应。现在两边分开取，各自说清是谁的登录态失效。
- 状态指令不再让用户「先解绑再重新绑定」——绑定指令早已允许直接覆盖重扫，
  两边说法互相矛盾。

### 变更

- **帮助与各种回复都收短。** 帮助改成一行一条，扫码、状态、昵称、PK 的提示
  去掉重复解释；模型出错一律说「调用模型失败」，未绑定一律先说怎么绑定。
- 组名补上带斜杠的别名（与爱农、爱完美同一处理由）。
- 提示词里 PK 的「互损」改成主要攻击输的一方；分数分差要跟实际差距相符，
  不再笼统要求「敢于给大的分差」；并钉住胜者那一行必须与分数一致。
- 用户文案去掉 ✅／⚠️／📱，与另外两个插件的纯文本风格一致。
- PK 念名字改用各人自己设的 PK 名字，优先于平台显示名。

### 工程

- 补 `test/test_prompts.py`：提示词的格式、端水禁令、字段白名单、段位不许编
  这些约束此前全靠人眼看。
- 补 `release.yml` 与 `test/test_workflow_shell.py`。
- AGENTS.md 补「结构」「指令落空与组别名」「模型调用」三节。
- `.gitattributes` 补行尾与二进制规则，去掉 `docs/` 的 `export-ignore`。

## [0.2.1] - 2026-10-14

### 新增

- **`/爱瓦 昵称 [名字]`**：改 PK 时被叫的名字，不带参数看当前值。名字默认取
  绑定时的平台显示名，以前想改只能重新绑定——而重绑要走完整套扫码流程。
  撞名时会提醒有几个人同名。

### 修正

- **昵称匹配改成精确优先、模糊兜底。** 以前只做子串，群里同时有「小明」和
  「小明同学」时，发 `/爱瓦 PK 小明` 会一次返回两个候选让人选——明明有个
  一模一样的。真重名时仍返回全部让用户选。

## [0.2.0] - 2026-10-14

这一版几乎全是线上踩出来的修正。0.1.0 只跑通过绑定与战绩，其余指令首次
真正被人用时才暴露问题。

### 修正

- **段位不再被编造。** 提示词要求「称号里带段位」，但段位（`tier_text`）只在
  主角色接口里，对局列表没有——模型拿不到就自己编了一个（钻石玩家被评成
  「铂金」，编得还很合理所以没人当场发现）。现在 `取对局()` 一并把角色返回，
  段位写在喂给模型的文本**首行**；取不到就明写「接口没给，不许提段位」。
- **状态指令不再给假绿灯。** 以前只查 `get_main_role_raw`，而那个接口只要
  Cookie 形状对就回 `result=0`，过期了照样回 0；真正需要登录态的
  `record/list` 早就 1003 了。于是出现「状态说绑定正常、转头锐评说登录态
  失效」，两句都是真话。现在状态会额外打一次战绩接口。
- **登录态过期后可直接重绑。** 以前战绩说「请重新绑定」，绑定却说
  「你已经绑定了，要换号先解绑」，用户被两边踢皮球而没人告诉他要先解绑。
  现在绑定指令先真查一次登录态，死了就允许直接覆盖重扫。
- **模型调用不再无限等。** `tool_loop_agent` 会把当前会话挂着的全部工具
  schema 塞进请求（这台机器十几个插件），锐评实测稳定卡死 90 秒以上，
  而同一 key 同一模型直连只要 12 秒。改成直接调 provider 的 `text_chat`
  （这些指令一个工具都不需要），带 90 秒超时并把重试压到 1 次；超时后
  换新请求再试一次——挂起的连接不会自己恢复。
- **PK 认人改成按昵称。** QQ 官方机器人**收不到 @别人**：实测
  `raw_message.mentions` 是空数组，组件链里只有 @机器人 一个，`message_str`
  里被 @ 的人连文本都没留下。现在绑定时记昵称，用 `/爱瓦 PK 群友昵称`
  模糊匹配；重名时列出候选让用户选，不自动挑第一个。
- **修掉协程对象混进提示词。** `_名字` 体内没有 await 却写成 async，调用点
  漏 await 后拿到协程对象（它是真值，`or "你"` 兜底不触发），f-string 渲染成
  `<coroutine object Main.名字 at 0x...>` 被当成玩家名字喂给模型，模型还
  一本正经点评了它。`_名字` 改回同步函数。
- **错误不再是黑箱。** 业务接口失败时消息里带上腾讯的 `result` 与 `err_msg`
  原文；只翻译成人话会让唯一线索消失。同样地，`result:1003` 不再一律当成
  登录过期——`wrong scene` 是我们自己的参数错，让用户重扫一百次也没用。

## [0.1.0] - 2026-10-13

首个版本。

### 新增

- **QQ 扫码登录**（`aiva/auth/ptlogin.py`）：出码 → 轮询 → 从 `auth://` 回调取
  `openid` 与 `access_token` → `app.mval.qq.com/go/auth/login_by_qq` 换 `userId`
  与 `tid`。全流程纯 HTTP，不需要浏览器侧车。
- **`/爱瓦 战绩`**：近期战绩聚合。胜负与胜率、场均 K/D/A、KDA、场均 ACS、
  场均回合净胜、最近走势、地图分布、常用特工。
- **`/爱瓦 锐评`**：模型写一段锐评，先给一句称号，再说打得好／问题／建议。
- **`/爱瓦 PK @群友`**：和另一个**已绑定**的人比。八项逐项对比由代码算死再交模型
  解说（「让模型自己比」的实测结果是端水话），模型只负责打分与解说。
- **`/爱瓦 开一局`**：随机生成一局竞技模式让模型推演。胜负按他自己的胜率抽，
  且**无论输赢都可能打出高 ACS**——回合制里「虽败犹荣」很常见。
- **`/爱瓦 解绑`**：删本地凭据文件。
- **落空兜底**：`/爱瓦 <不是子命令>` 时插件自己回提示，不放给模型编。

### 设计要点

- **字段白名单写进提示词。** 掌瓦列表没有 ADR、KAST、经济、攻防回合、
  命中率分布、武器明细、队友信息。必须明确告诉模型这些没有，否则它会照着
  别的 FPS 的指标体系编答案——这是爱完美踩过的坑。
- **地图与特工中文名取自 Riot 官方接口** `valorant-api.com`
  （`/v1/maps`、`/v1/agents`，`?language=zh-CN`）。凭记忆写错过一次：
  四个是错的（亚述／霜寒城谣／莲华／日落城），一个干脆是编的（禁地龛境）。
  正确的一组是：亚海悬城、霓虹町、裂变峡谷、源工重镇、微风岛屿、盐海矿镇、
  深海明珠、森寒冬港、莲华古城、日落之城、幽邃地窟。
- **凭据不进日志。** `扫码结果.__repr__` 只给 openid 长度，
  `storage.凭据摘要` 只给 userId 的前后各几位。

### 修正

- 修掉一个**只在容器加载时才暴露**的问题：`_取近期战绩` 在同一函数里既要
  `yield` 错误提示、又要 `return (文本, 摘要)`，触发
  `SyntaxError: 'return' with value in async generator`——AstrBot 导入插件
  直接失败并把插件卸掉。本地 `pytest` 一行都跑不到这条路径。改成抛
  `这句给用户`，并补了 `test/test_main_structure.py` 把这条钉住。

- 工程配置、`.gitattributes` 排除项与发布流程照 `astrbot_plugin_aiwm`
  拉平，两个插件保持同一套 CI 门禁。
- 图标：源图 `icon/aiva-icon.png`（用户绘制），经 `test/做图标.py` 生成
  256×256 的 `logo.png`。这张源图**不做亮度抠底**——图案暗部与背景亮度
  重叠（背景 r+g+b 40~57，人物面部阴影 55、红圈暗部 66），按亮度抠会把
  人物抠没；徽章外圈约占画布 87%，圆形裁切切不到图案，直接整张缩放。
  与 aiwm 那份脚本路线不同，原因写在脚本注释里。
